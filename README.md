# Traffic Signal Control System

A simple web-based Traffic Signal Control System developed to practice Git and GitHub workflows.

## Modules

### 1. Traffic Lights
Controls and displays the three basic traffic signals:
- Red
- Yellow
- Green

### 2. Timer
Provides a countdown timer for traffic signals.

### 3. Pedestrian Crossing
Allows pedestrians to request a crossing and temporarily stops traffic.
